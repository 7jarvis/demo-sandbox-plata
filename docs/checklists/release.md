# Чек-лист релиза

## Перед релизом

- [ ] Smoke и regression на релизном коммите зелёные, отчёт Allure открыт и просмотрен
- [ ] Во «flaky»/«broken» в Allure пусто; если тест перезапускали — причина разобрана
- [ ] Нет открытых дефектов Blocker и Critical
- [ ] Новые бизнес-правила описаны в `docs/test-cases` и покрыты автотестами
- [ ] Если менялся API — обновлён `openapi.yaml`, изменения обратно совместимы или согласованы с клиентами
- [ ] Ручные кейсы (TC-AUTH-07, TC-UI-16) пройдены, если затронуты вход или вёрстка
- [ ] Исследовательская проверка изменённых областей по чек-листам [money-operations](money-operations.md) и [web-ui](web-ui.md)
- [ ] Метрики в [quality-metrics.md](../quality-metrics.md) в целевых значениях

## После релиза

- [ ] Пройти smoke на production-подобном окружении (тестовым клиентом, не на реальных данных)
- [ ] Проверить логи и ошибки сервера за первый час: нет новых 5xx
- [ ] Сверить, что новые операции видны в истории с верными суммами
- [ ] Каждый дефект, найденный после релиза, получает автотест, который падал бы на нём
