# Чек-лист: веб-интерфейс

Для исследовательской проверки интерфейса после изменений вёрстки или
текстов. ⚙ — покрыто автотестами.

## Регистрация и вход

- [ ] ⚙ Отправить пустую форму регистрации — ошибка под каждым полем
- [ ] ⚙ Зарегистрировать занятый телефон — ошибка у поля телефона, остальные поля сохранились
- [ ] ⚙ Ввести неверный код — видно, сколько попыток осталось
- [ ] Ввести телефон с пробелами или скобками — подсказка о формате понятна
- [ ] Перейти по «Use a different number» — вернуться к вводу телефона
- [ ] ⚙ Выйти и открыть «My cards» по прямой ссылке — открывается вход

## Карты и операции

- [ ] ⚙ Выпустить карту — открывается её страница, сообщение об успехе
- [ ] ⚙ Попробовать выпустить четвёртую карту — понятное объяснение
- [ ] ⚙ Пополнить, оплатить, получить отказ — сообщения и баланс обновились
- [ ] ⚙ Заморозить и разморозить — меняются статус и кнопка
- [ ] ⚙ Открыть диалог блокировки, отменить; подтвердить без причины; подтвердить с причиной
- [ ] Закрыть диалог блокировки клавишей Esc — карта не заблокирована
- [ ] ⚙ Заблокированная карта: нет форм пополнения и оплаты, есть пояснение
- [ ] ⚙ Открыть чужую карту по ссылке — «Page not found»
- [ ] Кнопка отправки денежной формы блокируется после нажатия

## Доступность

- [ ] Пройти все формы только клавиатурой (Tab, Enter, пробел для переключателей)
- [ ] ⚙ Каждое поле имеет подпись; ошибка связана с полем (читается диктором)
- [ ] Сообщения об успехе и ошибке объявляются диктором (role status / alert)
- [ ] Фокус после открытия диалога внутри диалога, после закрытия — на кнопке «Block card»
- [ ] Контраст текста и статусов достаточный (статус не передаётся только цветом)

## Вёрстка (TC-UI-16)

- [ ] Ширина 375 px: нет горизонтальной прокрутки, плитки в одну колонку
- [ ] Ширина 375 px: формы и кнопки целиком видны, суммы читаются
- [ ] Длинное название карты (30 символов) и длинное имя мерчанта (60) не ломают вёрстку
- [ ] Имена и мерчанты с диакритикой (Cinépolis, Núñez) отображаются корректно
