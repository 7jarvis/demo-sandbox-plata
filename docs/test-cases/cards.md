# Выпуск карт

Правила: новая карта активна, баланс 0.00 MXN, срок действия — 4 года
(месяц выпуска), дневной лимит 100.00–100000.00, по умолчанию 20000.00.
Название необязательно, 1–30 символов, пробелы по краям убираются. У
клиента не больше трёх карт, которые не заблокированы.

<a id="tc-card-01"></a>
### TC-CARD-01. Выпуск карты с параметрами по умолчанию

**Приоритет:** высокий · smoke
**Автотесты:** `tests/api/test_cards.py::test_issue_card_with_defaults`, `test_issue_card_without_label`

**Предусловия:** клиент вошёл в приложение, карт нет.

**Шаги:**
1. Выпустить карту с названием `  Online shopping ` и без указания лимита.
2. Открыть список карт.
3. Выпустить вторую карту без названия.

**Ожидаемый результат:**
- Карта активна, баланс 0.00, потрачено сегодня 0.00, дневной лимит 20000.00, валюта MXN.
- Название сохранено без пробелов по краям; номер показан маской `5372 **** **** 1234`; срок действия — текущий месяц через 4 года.
- Карта есть в списке, данные совпадают.
- Карта без названия выпускается, название пустое.

<a id="tc-card-02"></a>
### TC-CARD-02. Дневной лимит на границах

**Приоритет:** средний
**Автотест:** `tests/api/test_cards.py::test_issue_card_with_daily_limit_on_boundary`

**Шаги:**
1. Выпустить карту с лимитом 100.00.
2. Выпустить карту с лимитом 100000.00.

**Ожидаемый результат:** обе карты выпущены с указанным лимитом.

<a id="tc-card-03"></a>
### TC-CARD-03. Недопустимый дневной лимит

**Приоритет:** средний
**Автотест:** `tests/api/test_cards.py::test_issue_card_with_invalid_daily_limit_is_rejected`

**Шаги:** выпустить карту с лимитом: `99.99`, `100000.01`, `0.00`, `500` (без копеек), `500.0`, `500.001`, `-100.00`, `1e3`.

**Ожидаемый результат:** каждый выпуск отклонён с ошибкой у поля лимита; карт у клиента не появилось.

<a id="tc-card-04"></a>
### TC-CARD-04. Длина названия карты

**Приоритет:** низкий
**Автотесты:** `tests/api/test_cards.py::test_card_label_length`, `test_blank_card_label_is_rejected`

**Шаги:** выпустить карты с названием из 1, 30, 31 символа и из одних пробелов.

**Ожидаемый результат:** 1 и 30 символов — карта выпущена; 31 символ и пробелы — отказ с ошибкой у названия.

<a id="tc-card-05"></a>
### TC-CARD-05. Не больше трёх карт

**Приоритет:** высокий
**Автотест:** `tests/api/test_cards.py::test_fourth_card_is_rejected`

**Предусловия:** у клиента три активные карты.

**Шаги:**
1. Выпустить четвёртую карту.
2. Открыть список карт.

**Ожидаемый результат:** выпуск отклонён (`CARD_LIMIT_REACHED`), в списке по-прежнему три карты.

<a id="tc-card-06"></a>
### TC-CARD-06. Заблокированная карта освобождает место

**Приоритет:** средний
**Автотест:** `tests/api/test_cards.py::test_blocked_card_does_not_count_towards_limit`

**Предусловия:** у клиента три активные карты.

**Шаги:**
1. Заблокировать одну карту (причина «потеряна»).
2. Выпустить новую карту.
3. Открыть список карт.

**Ожидаемый результат:** новая карта выпущена; в списке четыре карты: одна заблокированная и три активные.

<a id="tc-card-07"></a>
### TC-CARD-07. Список карт

**Приоритет:** средний
**Автотесты:** `tests/api/test_cards.py::test_new_customer_has_no_cards`, `test_card_list_contains_only_own_cards`

**Шаги:**
1. Открыть список карт нового клиента.
2. Выпустить по карте клиенту А и клиенту Б.
3. Открыть список карт клиента А.

**Ожидаемый результат:** у нового клиента список пуст (пустой список, а не ошибка); клиент А видит только свою карту.
