# Регистрация и вход

Правила: имя 2–100 символов (буквы, пробел, дефис, апостроф; лишние пробелы
убираются), телефон в формате +52 и 10 цифр, email уникален без учёта
регистра. Вход — по одноразовому коду из 6 цифр: код одноразовый, на него
3 попытки, запрос кода не раскрывает, зарегистрирован ли телефон.

<a id="tc-reg-01"></a>
### TC-REG-01. Регистрация нового клиента

**Приоритет:** высокий · smoke
**Автотест:** `tests/api/test_registration.py::TestRegistration::test_register_customer_returns_normalized_profile`

**Предусловия:** телефон и email ещё не зарегистрированы.

**Шаги:**
1. Открыть регистрацию.
2. Ввести имя `  Ana   María López ` (с лишними пробелами), свободный телефон и email заглавными буквами.
3. Отправить форму.
4. Войти по этому телефону и открыть профиль.

**Ожидаемый результат:**
- Регистрация успешна.
- В профиле имя `Ana María López` без лишних пробелов, email в нижнем регистре, телефон без изменений.
- Профиль после входа совпадает с данными, сохранёнными при регистрации.

<a id="tc-reg-04"></a>
### TC-REG-04. Некорректные данные при регистрации

**Приоритет:** средний
**Автотест:** `tests/api/test_registration.py::TestRegistration::test_register_with_invalid_field_is_rejected`

**Предусловия:** нет.

**Шаги:** для каждого значения из таблицы:
1. Заполнить форму корректными данными, кроме одного поля.
2. Ввести в это поле значение из таблицы и отправить форму.

| Поле | Значение | Почему неверно |
|---|---|---|
| Телефон | `+5255123456` | 9 цифр |
| Телефон | `+52551234567890` | 12 цифр |
| Телефон | `5512345678` | нет кода страны |
| Телефон | `+15512345678` | другая страна |
| Телефон | `+52 5512345678` | пробел |
| Email | `plainaddress`, `ana@localhost`, `ana@@example.com` | не email |
| Имя | `A` | 1 символ |
| Имя | `J0hn Smith` | цифра |
| Имя | `   ` | только пробелы |
| Имя | 101 символ | длиннее 100 |

**Ожидаемый результат:** регистрация отклонена, ошибка указана именно у этого поля. Клиент не создан.

### TC-AUTH-03. Блокировка кода после трёх неверных попыток

**Приоритет:** высокий
**Автотест:** `tests/api/test_auth.py::test_code_is_locked_after_three_wrong_attempts`

**Предусловия:** клиент зарегистрирован, код запрошен.

**Шаги:**
1. Трижды ввести неверный код.

3. Запросить новый код и войти с ним.

**Ожидаемый результат:**

- С новым кодом вход проходит.

### TC-AUTH-07. Истечение срока кода

**Приоритет:** средний · ручной
**Автотест:** нет — ожидание 5 минут в каждом прогоне слишком дорого. Для автоматизации нужен короткий срок кода в тестовом окружении (`OTP_TTL_SECONDS`), это задача в бэклоге.

**Предусловия:** клиент зарегистрирован.

**Шаги:**
1. Запросить код.
2. Подождать 5 минут.
3. Ввести код.

**Ожидаемый результат:** вход отклонён: «срок действия кода истёк, запросите новый» (`OTP_EXPIRED`).
