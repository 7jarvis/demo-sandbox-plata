# История операций

Правила: операции карты от новых к старым; фильтры по типу (пополнение,
оплата) и статусу (завершена, отклонена); постраничный вывод по 1–100
операций, по умолчанию 20; общее количество учитывает фильтры, но не
страницу.

**Общие предусловия для TC-HIST-01…03:** у карты операции в таком порядке:
пополнение 500.00; оплата «Cinépolis» 120.00 (завершена); оплата
«Liverpool» 900.00 (отклонена, недостаточно средств); оплата «Oxxo» 30.50
(завершена).

<a id="tc-hist-01"></a>
### TC-HIST-01. История показывает все операции с остатком

**Приоритет:** высокий · smoke
**Автотест:** `tests/api/test_history.py::test_history_lists_operations_newest_first`

**Шаги:**
1. Открыть историю карты.
2. Открыть карту.

**Ожидаемый результат:**

| № | Операция | Статус | Сумма | Мерчант | Остаток |
|---|---|---|---|---|---|
| 1 | оплата | завершена | 30.50 | Oxxo | 349.50 |
| 2 | оплата | отклонена | 900.00 | Liverpool | — |
| 3 | оплата | завершена | 120.00 | Cinépolis | 380.00 |
| 4 | пополнение | завершено | 500.00 | — | 500.00 |

Всего 4 операции; баланс карты равен остатку после последней операции (349.50).

### TC-HIST-02. Фильтры истории

**Приоритет:** средний
**Автотест:** `tests/api/test_history.py::test_history_filters`

**Шаги:** открыть историю с фильтрами из таблицы.

| Тип | Статус | Ожидается операций |
|---|---|---|
| пополнения | — | 1 |
| оплаты | — | 3 |
| — | отклонённые | 1 |
| — | завершённые | 3 |
| оплаты | завершённые | 2 |
| пополнения | отклонённые | 0 |

**Ожидаемый результат:** количество совпадает с таблицей, все показанные операции соответствуют фильтру.

<a id="tc-hist-03"></a>
### TC-HIST-03. Постраничный вывод

**Приоритет:** средний
**Автотест:** `tests/api/test_history.py::test_history_pagination`

**Шаги:** открыть историю страницами по 3 операции: первую, вторую, третью.

**Ожидаемый результат:** на страницах 3, 1 и 0 операций; на каждой странице общее количество 4; вместе страницы дают всю историю в том же порядке без повторов.
