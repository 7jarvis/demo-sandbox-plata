# Заморозка и блокировка карты

Правила: заморозка временная (клиент сам снимает), оплаты отклоняются,
пополнения проходят. Блокировка постоянная, с причиной «потеряна»,
«украдена» или «мошенничество»; заблокированную карту нельзя разблокировать,
заморозить, разморозить, пополнить, а оплаты по ней отклоняются. Баланс и
история заблокированной карты сохраняются.

Переходы состояний:

```
active ──freeze──► frozen ──unfreeze──► active
   │                  │
   └──block──► blocked ◄──block──┘      (из blocked переходов нет)
```

<a id="tc-stat-01"></a>
### TC-STAT-01. Заморозка и разморозка

**Приоритет:** высокий · smoke
**Автотест:** `tests/api/test_card_status.py::test_freeze_and_unfreeze`

**Предусловия:** клиент вошёл в приложение, карта активна.

**Шаги:**
1. Заморозить карту.
2. Открыть карту.
3. Разморозить карту.

**Ожидаемый результат:** после шага 1 статус «заморожена»; после шага 3 «активна»; остальные данные карты (баланс, лимит, номер) не изменились.

<a id="tc-stat-02"></a>
### TC-STAT-02. Повторная заморозка и разморозка активной карты

**Приоритет:** низкий
**Автотесты:** `tests/api/test_card_status.py::test_freeze_frozen_card_is_rejected`, `test_unfreeze_active_card_is_rejected`

**Шаги:**
1. Заморозить уже замороженную карту.
2. Разморозить активную карту.

**Ожидаемый результат:** шаг 1 отклонён (`CARD_ALREADY_FROZEN`), шаг 2 отклонён (`CARD_NOT_FROZEN`); статусы не изменились.

<a id="tc-stat-03"></a>
### TC-STAT-03. Блокировка карты

**Приоритет:** высокий · smoke (причина «потеряна»)
**Автотест:** `tests/api/test_card_status.py::test_block_card`

**Предусловия:** активная карта с балансом 75.00.

**Шаги:** заблокировать карту с причиной: «потеряна», «украдена», «мошенничество» (по одной карте на причину).

**Ожидаемый результат:** статус «заблокирована», причина сохранена, баланс 75.00 сохранён.

<a id="tc-stat-04"></a>
### TC-STAT-04. Блокировка необратима

**Приоритет:** критичный
**Автотест:** `tests/api/test_card_status.py::test_blocked_card_is_final`

**Предусловия:** карта заблокирована.

**Шаги:** по очереди: разморозить, заморозить, заблокировать ещё раз.

**Ожидаемый результат:** каждое действие отклонено (`CARD_BLOCKED`), карта остаётся заблокированной.

### TC-STAT-06. Блокировка без допустимой причины

**Приоритет:** низкий
**Автотест:** `tests/api/test_card_status.py::test_block_with_invalid_reason_is_rejected`

**Шаги:** заблокировать карту: без причины; с причиной `broken`; `LOST` (заглавными); с пустой причиной.
